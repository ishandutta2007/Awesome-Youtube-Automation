# Awesome-Youtube-Automation

# Top YouTube Automation Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Content Generation, Video Editing Automation & Channel Workflow Orchestration*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **YouTube Automation**. These tools help creators and automation-driven channels generate video scripts, create voiceovers, assemble edits, produce thumbnails, and publish content at scale — often with minimal manual intervention.

**Examples** include Zapier, Make, TubeMagic, Virvid, ytZolo, ShortGenius, InVideo AI, Crayo AI, Digital Maker AI, and Submagic (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom automation pipelines, and transparent content workflows — ideal for faceless channel operators, developers building video automation tools, and creators avoiding per-video subscription costs.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Zapier](https://zapier.com/)**  
  No-code automation platform connecting 7,000+ apps with multi-step Zaps. Commonly used to trigger YouTube workflows from RSS feeds, Google Sheets, and other tools.

- **[Make](https://www.make.com/)**  
  Visual automation platform with scenario builder, routers, and 2,000+ app connectors. Popular for YouTube upload notifications and cross-platform content distribution.

- **[TubeMagic](https://tubemagic.com/)**  
  AI-powered YouTube growth tool with video idea generation, script writing, SEO optimization, and competitor analysis.

- **[Virvid](https://virvid.ai/)**  
  AI video generation platform for creating faceless YouTube videos from text prompts.

- **[ytZolo](https://ytzolo.com/)**  
  YouTube automation platform for bulk video creation, uploading, and channel management.

- **[ShortGenius](https://shortgenius.com/)**  
  AI-powered short-form video creation platform for YouTube Shorts, TikTok, and Reels.

- **[InVideo AI](https://invideo.io/)**  
  AI video creation platform turning text prompts into complete videos with stock footage, voiceover, and editing.

- **[Crayo AI](https://crayo.ai/)**  
  AI video generation and automation platform for creating short-form content at scale.

- **[Digital Maker AI](https://digitalmaker.ai/)**  
  AI-powered YouTube automation suite with script generation, voiceover, and video assembly.

- **[Submagic](https://submagic.co/)**  
  AI-powered captioning and video editing platform with auto-subtitles, B-roll suggestions, and viral hooks.

## Open-Source GitHub Projects

- **[MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)**  
  Open-source tool generating high-definition short videos from a single topic or keyword. Automates script writing, material sourcing, subtitles, background music, and video assembly. Supports multiple LLM providers (OpenAI, Moonshot, Azure, Ollama) and TTS engines (EdgeTTS, Azure, gTTS). Features batch generation, multiple video sizes (9:16 and 16:9), and Docker deployment. MIT licensed, 60,000+ GitHub stars.

- **[MoneyPrinterV2](https://github.com/FujiwaraChoki/MoneyPrinterV2)**  
  Successor to MoneyPrinter focused on automating the entire online money-making process including YouTube Shorts and Twitter bot automation. Features modular architecture, CRON scheduling, and affiliate marketing integration. MIT licensed.

- **[ShortGPT](https://github.com/RayVentura/ShortGPT)**  
  Open-source framework for automated short-form content creation. Features script generation, TTS voiceover, asset sourcing, caption generation, and video rendering. Supports multiple languages and LLM providers. MIT licensed.

- **[AutoShorts.ai](https://github.com/)**  
  Open-source alternative for automated short video generation with AI-powered script writing and assembly.

- **[OpenShorts](https://github.com/)**  
  Self-hosted platform for generating YouTube Shorts and TikTok videos from text prompts.

- **[n8n](https://github.com/n8n-io/n8n)**  
  Fair-code workflow automation platform with 400+ integrations, visual builder, custom code nodes, and AI Agent nodes. The leading open-source alternative to Zapier and Make for YouTube automation pipelines. Self-hosted with no per-task pricing.

- **[Activepieces](https://github.com/activepieces/activepieces)**  
  Open-source no-code AI-first automation tool with 600+ integrations, MIT-licensed Community Edition, and unlimited flows when self-hosted. Alternative to Zapier and Make.

- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)**  
  Feature-rich command-line video downloader and archive tool for YouTube and 1,000+ other sites. Essential for content research, archival, and pipeline automation. Unlicense licensed.

- **[Whisper](https://github.com/openai/whisper)**  
  OpenAI's open-source speech recognition model for transcription, translation, and voiceover generation. MIT licensed.

- **[Coqui TTS](https://github.com/coqui-ai/TTS)**  
  Open-source text-to-speech toolkit with voice cloning, multi-speaker support, and 1,100+ pre-trained models across 110+ languages. MPL-2.0 licensed.

- **[Piper TTS](https://github.com/rhasspy/piper)**  
  Fast, local neural text-to-speech system optimized for Raspberry Pi and low-resource devices. MIT licensed.

- **[Bark](https://github.com/suno-ai/bark)**  
  Transformer-based text-to-audio model generating highly realistic speech, music, and sound effects. MIT licensed.

- **[FFmpeg](https://github.com/FFmpeg/FFmpeg)**  
  Complete cross-platform solution for recording, converting, and streaming audio/video. The foundation of nearly all open-source video automation pipelines. LGPL/GPL licensed.

- **[Auto-Editor](https://github.com/WyattBlue/auto-editor)**  
  Command-line application for automatically editing video and audio by analyzing volume levels. Ideal for removing silence from talking-head content. Unlicense licensed.

- **[MoviePy](https://github.com/Zulko/moviepy)**  
  Python library for video editing with cutting, concatenation, title insertion, and custom effects. MIT licensed.

- **[Remotion](https://github.com/remotion-dev/remotion)**  
  Framework for creating videos programmatically using React. Enables dynamic, data-driven video generation at scale. Company license with free tier for individuals and small teams.

- **[OpenTimelineIO](https://github.com/AcademySoftwareFoundation/OpenTimelineIO)**  
  API and interchange format for editorial timeline information from Pixar. Apache 2.0 licensed.

- **[AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)**  
  Autonomous AI agent framework for building multi-step automation workflows including content research and generation. MIT licensed.

- **[ComfyUI](https://github.com/comfyanonymous/ComfyUI)**  
  Powerful node-based Stable Diffusion interface for generating thumbnails, B-roll, and visual assets programmatically. GPL-3.0 licensed.

- **[Stable Diffusion WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui)**  
  Browser-based interface for Stable Diffusion with API support for automated image generation. AGPL-3.0 licensed.

- **[Ollama](https://github.com/ollama/ollama)**  
  Run large language models locally for script generation, content ideation, and metadata optimization. MIT licensed.

- **[Open WebUI](https://github.com/open-webui/open-webui)**  
  Self-hosted web interface for LLMs with pipeline support for custom automation workflows. MIT licensed.

### Additional Strong Open-Source Options

- **[MoneyPrinterPlus](https://github.com/ddean2009/MoneyPrinterPlus)** — AI-powered batch video generation with support for multiple LLMs and TTS engines. Apache 2.0 licensed.
- **[Faceless Video Generator](https://github.com/)** — Open-source pipeline for faceless channel content creation from Reddit stories and articles.
- **[YouTube Uploader](https://github.com/porjo/youtubeuploader)** — Command-line tool for automated YouTube video uploads with OAuth2. MIT licensed.
- **[Google APIs Python Client](https://github.com/googleapis/google-api-python-client)** — Official Python client for YouTube Data API v3, enabling programmatic upload, metadata management, and analytics retrieval.
- **[Pytube](https://github.com/pytube/pytube)** — Lightweight Python library for downloading YouTube videos. MIT licensed (note: maintenance has slowed).
- **[Instaloader](https://github.com/instaloader/instaloader)** — Download pictures, videos, and metadata from Instagram for cross-platform automation. MIT licensed.
- **Orchestration Tools** — Apache Airflow, Temporal, Prefect for scheduling video generation pipelines.
- **Vector Databases** — Qdrant, Weaviate for semantic content search and idea deduplication.

**Frameworks for building custom systems**: Combine **MoneyPrinterTurbo** or **ShortGPT** for video generation, **Ollama** or **OpenAI Whisper** for AI content, **Piper TTS** or **Coqui TTS** for voiceover, **FFmpeg** and **MoviePy** for video assembly, **n8n** for workflow orchestration, and **ComfyUI** for thumbnail generation to build a complete self-hosted YouTube automation pipeline.
